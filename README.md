
# وضوح | Wuduh

نموذج تفاعلي يقترح تحسين تجربة مستخدمي تابي من خلال جمع أهم المعلومات في رحلة مالية واضحة:

- عرض الالتزامات والمدفوعات القادمة قبل الشراء.
- تتبع حالة الاسترجاع والمبلغ المسترد.
- توضيح سبب رفض العملية والخطوة التالية للمستخدم.

## تجربة النموذج

تم تطوير هذا النموذج للمشاركة في تحدي Tabby Imagine.
